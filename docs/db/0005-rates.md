# Migration 0005 — نرخ‌ها و هزینه‌ها: ارز، حمل، بیمه و هزینه‌ها، HS code، مالیات

- **وضعیت:** ✅ تأیید شد (2026-09-27).
  - روی Postgres محلی سندباکس اجرا و تست شد، هم قبل و هم بعد از migrate.
  - **روی لیارا هنوز اجرا نشده.** مالک بعد از استقرار کد اجرا می‌کند.
- **فایل SQL:** `web/drizzle/0005_rates.sql`
- **نوع تغییر:** فقط افزودنی: ۹ جدول تازه. به هیچ جدول، ستون یا داده‌ی موجودی دست نمی‌زند.
- **تعریف در کد:** `web/src/db/schema/rates.ts`
- **قاعده:** جدول‌های `exchange_rates` و `…_versions` فقط افزودنی‌اند (تغییر = ردیف تازه). توضیح کامل: `docs/infoyaarchin.md` بخش ۲۱.

| جدول | چیست |
|---|---|
| `currencies` | ارزها: کد سه‌حرفی (CHECK)، اسم فارسی، فعال، `is_base` (تومان = IRT) |
| `exchange_rates` | نرخ به تومان؛ `kind` بازار یا گمرکی، `rate_date` (تاریخ تهران)، ثبت‌کننده. CHECK: نرخ > ۰ |
| `shipping_methods` | ۴ روش ثابت: air، sea، land، rail (CHECK) |
| `shipping_method_versions` | نرخ هر کیلو، هر م³، ضریب وزن حجمی، حداقل هزینه، ارز، حداقل/حداکثر روز رسیدن (۱ تا ۳۶۵)، فعال، `valid_from` |
| `cost_items` | آیتم هزینه با اسم دلخواه (بیمه، ترخیص، …) |
| `cost_item_versions` | نوع محاسبه (fixed، percent، per_kg، per_cbm، formula)، مقدار، پایه‌ی درصد، متن فرمول، ارز، روش‌های حمل مشمول (null = همه)، فعال، `valid_from` |
| `hs_codes` | کد HS فقط رقم (۴ تا ۱۲؛ CHECK) |
| `hs_code_versions` | شرح، فعال، حقوق ورودی درصد (با پایه) یا مبلغ ثابت (ارز و «به ازای»)، `valid_from`، `import_batch` |
| `tax_versions` | درصد ارزش افزوده (۰ تا ۱۰۰)، پایه‌ی آن، `customs_rate_for` (نرخ گمرکی برای duty و/یا vat) |

- **کلیدهای خارجی:** همه RESTRICT (ارز یا کد یا آیتمی که نسخه دارد پاک نمی‌شود)، به‌جز `created_by` که با حذف کاربر null می‌شود.
- **Seed** (داده، نه ساختار؛ فقط اگر جدول‌ها باشند):
  - دسترسی‌های `rates.enter`، `costs.manage`، `hs.manage`؛
  - ارزهای تومان (پایه)، دلار و یوان؛ ۴ روش حمل (بدون نرخ؛ تا ادمین نرخ ندهد در سایت نمی‌آیند)؛
  - نسخه‌ی اول مالیات فقط اگر جدول خالی باشد: ۱۰٪ روی کالا + حمل، نرخ گمرکی برای حقوق ورودی و ارزش افزوده.
- **قبل از migrate** سایت و پنل خطا نمی‌دهند (`ratesReady()` در `src/lib/db-ready.ts`):
  - کارت «قیمت تمام‌شده» در سایت «به‌زودی» نشان می‌دهد؛ میانگین قیمت مثل قبل فقط دلاری است؛
  - بخش «نرخ‌ها و هزینه‌ها» پیام «اول migrate» می‌دهد؛ فیلد HS محصول مثل قبل متن آزاد است.

## اجرا روی لیارا (به همین ترتیب)
1. بک‌آپ دیتابیس `yaarchin-db`.
2. Merge و صبر تا «Deploy to Liara» سبز شود.
3. در کنسول برنامه:
   - `npm run db:migrate`
   - `npm run db:seed`
   - (اختیاری) `npm run db:seed-demo` تا نرخ‌ها و هزینه‌های نمونه برای محصولات demo ساخته شود.
4. در پنل: نرخ امروز دلار و یوان، نرخ روش‌های حمل، آیتم‌های هزینه و لیست HS را وارد کنید.
5. قبل از افتتاح سایت: `npm run db:seed-demo -- --remove` (داده‌ی نمونه‌ی نرخ‌ها را هم پاک می‌کند).
