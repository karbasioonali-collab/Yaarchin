# Migration 0003 — مشتری: علاقه‌مندی، پروفایل کسب‌وکار، دسته‌های مورد علاقه، کد پیامکی

- **وضعیت:** ✅ تأیید شد (2026-09-25).
  - روی Postgres محلی سندباکس اجرا و تست شد، هم قبل و هم بعد از migrate.
  - **روی لیارا هنوز اجرا نشده.** مالک بعد از استقرار کد اجرا می‌کند.
- **فایل SQL:** `web/drizzle/0003_customer.sql`
- **نوع تغییر:** فقط افزودنی: ۴ جدول تازه. هیچ جدول، ستون یا داده‌ی موجودی عوض نمی‌شود.
- **تعریف در کد:** `web/src/db/schema/customer.ts`

| جدول | چیست | کلید و قیدها |
|---|---|---|
| `favorites` | محصولات ذخیره‌شده‌ی هر مشتری | کلید (user_id، product_id)؛ با حذف کاربر یا محصول پاک می‌شود |
| `customer_profiles` | پروفایل کسب‌وکار اختیاری: نوع فعالیت، شهر، سابقه‌ی واردات | یک ردیف برای هر کاربر؛ CHECK: نوع فعالیت فقط shop، wholesale، online، personal یا other |
| `customer_interests` | دسته‌های مورد علاقه | کلید (user_id، category_id)؛ با حذف دسته پاک می‌شود |
| `otp_codes` | کد یک‌بارمصرف پیامکی (ورود یا تأیید موبایل) | فقط هش کد؛ انقضا، شمار تلاش، زمان مصرف؛ CHECK روی purpose |

- رفتار مشتری (بازدید، ورود، علاقه‌مندی) جدول تازه نمی‌خواهد. در جدول موجود `events` (از migration ۰۰۰۰) ثبت می‌شود.
- **Seed** (داده، نه ساختار):
  - دسترسی‌های `customers.view` و `customers.manage` (گروه «مشتریان»)؛
  - تنظیم `auth.customer_session_days` = ۳۰.

## اجرا روی لیارا (به همین ترتیب)
1. بک‌آپ دیتابیس `yaarchin-db`.
2. Merge و صبر تا «Deploy to Liara» سبز شود.
   - در این فاصله سایت بدون خطا کار می‌کند.
   - ثبت‌نام، ورود و «بازدیدهای اخیر» هم کار می‌کنند.
   - قلب علاقه‌مندی و پروفایل کسب‌وکار پیام «به‌زودی» می‌دهند (`customerReady()` در `src/lib/db-ready.ts`).
3. در کنسول برنامه:
   - `npm run db:migrate`
   - `npm run db:seed`
