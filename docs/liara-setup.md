# راه‌اندازی روی لیارا

> هیچ connection string، رمز یا کلیدی را در ریپو یا چت قرار ندهید. همه فقط در «متغیرهای محیطی» برنامه در پنل لیارا ثبت شوند.

## ۱. ساخت دیتابیس PostgreSQL
1. در پنل لیارا به منوی **دیتابیس** بروید، **راه‌اندازی دیتابیس** را بزنید و **PostgreSQL** را انتخاب کنید.
2. **نسخه:** جدیدترین نسخه‌ای که لیارا پیشنهاد می‌دهد (۱۶ یا بالاتر). کد پروژه با ۱۳ به بالا کار می‌کند، ولی نسخه‌ی جدیدتر بهتر است.
3. **شناسه:** مثلاً `yarchin-db`. این شناسه در کل حساب لیارا باید یکتا باشد.
4. **شبکه‌ی خصوصی:** یک شبکه‌ی خصوصی بسازید یا انتخاب کنید، مثلاً `yarchin-net`. برنامه‌ی سایت هم بعداً در همین شبکه قرار می‌گیرد.
5. **منابع:** برای شروع، کوچک‌ترین پلن کافی است و بعداً قابل ارتقاست.
6. **pgvector:** اگر در صفحه‌ی ساخت گزینه‌ی افزونه‌ها (Extensions) وجود دارد، **pgvector** را فعال کنید. اگر نبود، بعد از ساخت از **تنظیمات دیتابیس ← افزونه‌ها** فعالش کنید.
   - طبق مستندات لیارا، pgvector روی دیتابیس‌های لیارا فعال‌شدنی است ولی **ایندکس HNSW پشتیبانی نمی‌شود**. در مرحله‌ی چت از ایندکس **IVFFlat** استفاده می‌کنیم.
   - **راه اطمینان:** بعد از ساخت، در بخش افزونه‌های تنظیمات دیتابیس ببینید pgvector در لیست هست و روشن است. روش دقیق‌تر این است که بعد از راه‌اندازی برنامه، این دستور در کنسول اجرا شود:
     `select name, default_version, installed_version from pg_available_extensions where name = 'vector';`
     اگر یک ردیف برگرداند، pgvector در دسترس است.

## ۲. اطلاعات اتصال
- بعد از ساخت، در صفحه‌ی دیتابیس بخش **اطلاعات اتصال / لینک‌های اتصال** دو نوع لینک دارد:
  - **شبکه‌ی خصوصی:** برای برنامه‌ی سایت روی لیارا. امن‌تر و سریع‌تر است. **این را برای `DATABASE_URL` استفاده کنید.**
  - **شبکه‌ی عمومی:** فقط برای اتصال از بیرون (مثلاً ابزار مدیریت دیتابیس). لازم نیست فعالش کنید.
- **URI** یک رشته به شکل `postgresql://USER:PASSWORD@HOST:PORT/DBNAME` است.

## ۳. متغیرهای محیطی برنامه (هنگام ساخت برنامه‌ی سایت)
برنامه‌ی سایت (پلتفرم **Next.js**) در مرحله‌ی استقرار ساخته می‌شود و **در همان شبکه‌ی خصوصی** قرار می‌گیرد. در **تنظیمات برنامه ← متغیرهای محیطی** این‌ها را ثبت کنید:

| نام | مقدار |
|---|---|
| `DATABASE_URL` | URI **شبکه‌ی خصوصی** دیتابیس |
| `APP_ENCRYPTION_KEY` | کلید تصادفی ۳۲ بایتی به‌شکل base64 (راه ساخت در پایین) |

**ساخت `APP_ENCRYPTION_KEY`:** در کنسول برنامه روی لیارا یا هر سیستمی که Node دارد، این دستور را اجرا کنید:
```
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```
⚠️ **این کلید را جایی امن هم نگه دارید و هیچ‌وقت عوضش نکنید.** رمزهای ورود دومرحله‌ای با این کلید رمز شده‌اند و اگر کلید عوض یا گم شود، ورود دومرحله‌ای همه‌ی کاربران باید از نو ریست شود.

## ۴. اولین اجرا (یک‌بار، از کنسول برنامه روی لیارا)
```
npm run db:migrate      # ساخت جدول‌ها (migration 0000 تأییدشده)
npm run db:seed         # نقش‌ها، دسترسی‌ها، سوئیچ‌ها
npm run create-admin    # نام، موبایل و رمز اولین ادمین را می‌پرسد
```
بعد به آدرس `/admin` بروید و وارد شوید. در اولین ورود، ورود دومرحله‌ای با اپ Google Authenticator راه‌اندازی می‌شود. **کدهای بازیابی** را بیرون از گوشی یادداشت کنید.

## ۵. migrationهای بعدی
هر migration جدید:
1. قبل از اجرا با توضیح در `docs/db/` پیشنهاد می‌شود.
2. بعد از **تأیید** مالک، اول از بخش **بک‌آپ** دیتابیس در لیارا یک بک‌آپ گرفته می‌شود.
3. بعد `npm run db:migrate` اجرا می‌شود.
